# Third-party license texts

This directory accompanies `THIRD_PARTY_NOTICES.md`.

It contains the standard license texts relevant to third-party components that
were identified as requiring explicit attention in the SEEKMORE dependency
license scan before the initial public release.

For packaged Windows/macOS releases, also preserve any package-specific
LICENSE/NOTICE files shipped by the exact binary versions included in that
build. This is especially important for platform-specific Sharp/libvips
packages, whose bundled native libraries have their own third-party notices.
